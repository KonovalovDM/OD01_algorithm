# OD01_algorithm
 Введение в алгоритмы и структуры данных

Алгоритм действий для определения, является ли строка палиндромом:
1.	Приведение строки к единому регистру:
	Чтобы игнорировать различия между строчными и прописными буквами, переводим всю строку в нижний или верхний регистр.
2.	Удаление лишних символов:
	Убираем все символы, кроме букв и цифр (например, пробелы, знаки препинания).
3.	Сравнение строки с её перевёрнутой копией:
	Если строка равна своей перевёрнутой версии, она является палиндромом.
